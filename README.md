Welcome to the STEM Mash-Up Final! This project is a single-page, highly interactive educational web application that turns a standard science worksheet into a cosmic, 3D-animated experience. Students can calculate temperatures using virtual crickets, ponder the rotation of the Earth, and dissect the anatomy of a candle flame.

## ✨ Features
*   🌌 **Immersive 3D Background:** Powered by Three.js, the background features a rotating Earth, a hopping 3D cricket, rising flame particles, and a dynamically rotating starry galaxy.
*   🦗 **Interactive Chirp-O-Meter:** A built-in JavaScript calculator that converts cricket chirps (in 15 seconds) into Fahrenheit temperature.
*   🔥 **Auto-Graded Quiz:** Features matching, fill-in-the-blank, and multiple-choice questions about the science of fire. Hit submit, and the page instantly auto-grades the answers!
*   🎨 **Gorgeous UI/UX:** Custom CSS variables, smooth gradients, glowing borders, and playful Google Fonts (Lobster and Quicksand) make learning visually exciting.
*   📱 **Fully Responsive:** Works beautifully on desktops, tablets, and mobile devices.

## 🚀 The Experiments

### 1. Chirp-O-Meter 🌡️
Did you know crickets are cold-blooded thermometers? Students count chirps, use the interactive calculator, and write their very own weather forecast based on cricket data!

### 2. Sun Dial DIY ⏳
A challenge exploring how humans told time before digital clocks. Students learn the basics of making a sundial and are prompted to explain the shadow's movement in relation to Earth's rotation.

### 3. The Fiery Truth 🔥
A deep dive into the physics of a flame. Students match flame zones (Blue Base, Yellow Middle, Invisible Flame) to their scientific properties and learn about combustion chemistry.

## 🛠️ Tech Stack
*   **Structure:** HTML5
*   **Styling:** CSS3 (Flexbox, CSS Variables, Custom Gradients, Glowing Shadows)
*   **Logic:** Vanilla JavaScript (DOM manipulation, auto-grading algorithms)
*   **3D Graphics:** Three.js (via CDN)

## 💻 How to Run Locally
Because this project is built entirely with vanilla web technologies, installation is beautifully simple. No build steps, no `npm install`, and no dependencies to download!

**Clone the repository:**
```bash
git clone https://github.com/2ndChances520/stem-mash-up.git
```

**Open the file:**
Simply double-click the `index.html` file to open it in your default web browser.
*(Note: Ensure you have an active internet connection so the Three.js CDN and Google Fonts can load properly).*
